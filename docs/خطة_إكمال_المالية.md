## 2. تعريف «اكتمال المالية» الذي سأُحاسَب عليه

1. كل شاشة مالية من الـ30 لها: مسار HTTP + قالب + صلاحية + تدقيق (audit) + اختبار.
2. كل وحدة مرتبطة بمحرّك الأستاذ: لا رقم يُعرض إلا من قيد مُرحّل.
3. عزل الشركة/الفرع في كل استعلام (لا تسريب بين شركتين).
4. العملة: رمز + سعر + تحويل، وكل تقرير يعرض عملته الأساسية.
5. الفترات والإقفال: لا ترحيل في فترة مقفلة، ولا ترحيل مرتبط قبل الاعتماد.
6. تقارير: ميزان مراجعة، قائمة دخل، ميزانية عمومية، أستاذ حساب، أعمار ديون — كلها من نفس المحرك.
7. `cargo test --release` أخضر بالكامل + فحص بصري موثّق بلقطات.
8. كل ملف ≤ 700 سطر، والحجم الكلي تحت المراقبة.
