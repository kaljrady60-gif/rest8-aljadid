# قانون تفعيل الأدوات

**الحالة:** معتمد من المالك بتاريخ 2026-11-01. هذه الأدوات مأذون باستخدامها **دون استئذان متكرر**؛ الإذن المسبق يبقى فقط لأي أداة خارج هذه القائمة.

## 1) الأدوات المفعّلة إلزاميًا في كل دفعة

| الأداة | الأمر | متى تُشغَّل | القيمة |
|---|---|---|---|
| `rustfmt` | `cargo fmt --all -- --check` | كل دفعة | تنسيق موحد بلا نزاعات أسلوب |
| `clippy` | `cargo clippy --all-targets -- -D warnings` | كل دفعة | أخطاء منطقية وأسلوبية قبل التشغيل |
| `cargo test` | `cargo test --locked` | كل دفعة | إثبات السلوك ومنع الانحدار |
| بوابات المشروع | `python3 quality/gates.py` | كل دفعة | حجم الملفات، النظافة، تطابق العقود |
| `cargo nextest` | `cargo nextest run` | عند توفرها | تشغيل أسرع وعزل أفضل للاختبارات |
| `cargo deny` | `cargo deny check` | عند تغيير التبعيات | رخص وثغرات ومصادر |
| `cargo audit` | `cargo audit` | أسبوعيًا أو عند تحديث تبعية | ثغرات معروفة |
| `cargo machete` | `cargo machete` | عند تغيير `Cargo.toml` | تبعيات غير مستخدمة |
| `cargo llvm-cov` | `cargo llvm-cov --summary-only` | عند إضافة منطق مالي | نسبة التغطية الفعلية |
| `cargo mutants` | `cargo mutants --file <ملف>` | على الملفات المالية الحسّاسة | كشف ضعف الاختبارات |
| `proptest` | ضمن الاختبارات | قواعد المال والتوازن | حالات حدّية عشوائية |
| `ruff` | `ruff check quality/` | عند تعديل سكربتات Python | نظافة سكربتات الجودة |
| `playwright` (Python) | سكربتات `tests/*.py` | كل تغيير مرئي | اختبار واجهة حقيقي + لقطات |

## 2) قواعد الاستخدام

1. **لا ادعاء تشغيل بلا تشغيل.** كل أداة تُذكر بنتيجتها الفعلية أو يُذكر تعذّرها وسببه.
2 . **النتيجة السلبية نتيجة.** فشل أداة يُصلح أو يُوثّق، ولا يُخفى.
3. **الأدوات تخدم الاختبار لا العكس:** لا تُقبل أداة تُبطئ الحلقة أكثر من قيمتها؛ تُشغَّل على النطاق المتأثر فقط.
4. **الإضافة الجديدة:** أي أداة خارج القائمة تحتاج إخبار المالك باسمها وفوائدها وعيوبها وأثرها قبل تثبيتها.
5. **الأمان:** لا فحص اختراق أو حمل على قاعدة بيانات تشغيلية؛ الاختبارات على قاعدة معزولة أو مؤقتة.

## 3) حدود معلومة

- `cargo-mutants` بطيء على المعالج المتاح: يُشغَّل على ملف واحد متى لزم، لا على المشروع كله.
- `Miri` و`fuzz` غير مفعّلين (تكلفة تشغيل عالية على هذه البيئة) — يُذكر ذلك صراحة عند الحاجة.
- اختبارات المتصفح تحتاج `python3 -m playwright install chromium` بعد أي إعادة تهيئة للبيئة.
